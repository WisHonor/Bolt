Bolt v0.1 is the first release of Bolt, a version control system for code and large binary files together, with its own engine and storage format: it is not built on Git.

It is an early release, for one person on one computer. There is no server yet, so no sharing, merging or locking.

## What it does

- **Saves and history:** `start`, `save`, `status`, `changes`, `history`, `show`, `goto`, `discard`.
- **Lines and shelves:** `line` to try ideas on a line of their own; `shelf` and `unshelf` to put changes aside.
- **Undo for everything:** `bolt undo` takes back any command that changed something, and `bolt redo` brings it back.
- **Presets:** `bolt start` asks what kind of project it is (Game, Code or Custom); Game and Code write their rules into `bolt.toml` and `.boltignore`, and `bolt setup` shows them and switches presets.
- **Big files:** cut into chunks, so a change to part of a file stores only the part that changed.
- **Coming from Git:** `bolt import` brings in a Git repository, Git LFS files included.
- **Looking after a project:** `tidy` and `verify`.

What Bolt writes on disk is documented in `docs/storage-format.md` and frozen from this version: every later Bolt reads what v0.1 wrote.

## Download

One archive per system: `bolt-0.1.0-<system>.zip` for Windows, `.tar.gz` for Linux and macOS (Apple silicon and Intel). Each holds the program, `README.md`, the user guide (`docs/guide.md`) and `THIRD-PARTY-LICENSES.html`.

`SHA256SUMS` lists a SHA-256 for each archive. Check a download with `sha256sum -c --ignore-missing SHA256SUMS` on Linux, or `shasum -a 256 -c --ignore-missing SHA256SUMS` on macOS; the guide's "Installing" section has the Windows command. A match says the file is the one this release's workflow uploaded and arrived whole; it doesn't say who made it, since nothing is signed.

## Not signed

The programs aren't signed. Windows SmartScreen may say "Windows protected your PC" (choose "More info", then "Run anyway"), and macOS Gatekeeper refuses a program from an unknown developer the first time (System Settings, Privacy & Security, "Open Anyway"). The guide's "Installing" section has the steps. Signing is planned.

## No license yet

Bolt has no license yet; one will be chosen before v0.1 is published.

## Known limits

No server, no merging, no locking, no repair (`bolt verify` finds damage but can't fix it), and no export to Git yet. The guide's last section, "What v0.1 doesn't do yet", lists them all.

## For scripts

Every command can print `--json`. The formats are documented in `docs/json.md` and frozen from this version (`bolt_json` 1).
