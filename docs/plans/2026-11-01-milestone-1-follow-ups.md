# Milestone 1 follow-ups

> Items the milestone 1 reviews and its red-team fixes deferred (2026-11-01 and 2026-11-02). Each later milestone's plan must pull in the ones that apply to it. The "must do" items are load-bearing: forgetting them causes a security or data bug. Done items are struck through, with the date.

Measure decision 023's speed bar after this. |
| Milestone 3 | Write-out's cases from the review of Git's published vulnerabilities (security.md §7, 2026-11-02): never write a `.git` spelling on any system, NTFS or vfat drives mounted on Linux included (CVE-2019-1353); compare names with the real short names of `.bolt` and `.git` (`GetShortPathNameW`), since NTFS switches to hashed short names after four clashes; refuse a link whose name clashes with a folder's on a drive that ignores letter case, and create links last (CVE-2021-21300, CVE-2024-32002); never look at a link's target (Git for Windows' NTLM leak, gitoxide GHSA-xw69); refuse `\` and drive letters (CVE-2019-1354, CVE-2019-1351; the Windows row above); refuse device names, `COM¹`–`COM³` and `LPT¹`–`LPT³` included; write explicit 0644 and 0755 modes (gitoxide CVE-2025-22620); keep no cache of checked folder prefixes (gitoxide 2026). |
