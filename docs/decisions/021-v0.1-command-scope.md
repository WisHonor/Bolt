# 021 — v0.1 command scope

- **Status:** Accepted
- **Date:** 2026-10-31
- **Agenda topic:** 18 (design review)
- **Refined by:** [decision 055](055-lines-in-v0.1.md) (lines in v0.1); [decision 073](073-shelves.md) (shelves); [decision 074](074-save-amend.md) (`save --amend`); [decision 157](157-v0.2-in-four-milestones.md) (`who` comes in milestone 10, and other ways of editing older saves wait until after v0.2)
- **Refines:** the command set in [decision 017](017-commands-and-output.md)

## Context

The design review found that the documents disagreed about which commands v0.1 includes: `goto` offers to shelve (decision 003), but `shelf` wasn't in the v0.1 list; and no command edits a past save, so change IDs would never pay off in v0.1.

## Decision

- **In v0.1:** `shelf` and `unshelf`; `save --amend`, which replaces the last save with the current changes and/or a new message while keeping its change ID.
- **Later:** `who` (v0.2); `reverse` (v0.3, once other people can have your saves); other ways of editing older saves (v0.2 or later).

## Consequences

- milestones.md places `shelf`, `unshelf` and `save --amend` in milestone 4 (Undo everything), next to the diary they rely on.
- `goto` (milestone 3) offers to save or discard; the "shelve" option arrives with milestone 4.
- design.md §5.15 marks `who` and `reverse` with the versions they arrive in.
