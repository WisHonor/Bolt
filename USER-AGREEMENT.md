## 5. What Opalro sends: nothing

Opalro sends nothing, to us or to anyone else: your projects, your file names and the way you work stay on your computer.

- Opalro has no code that uses a network, and none of the code built into it does either.
- Each build we release is checked first. The check reads the list of what the program asks the operating system for, and stops the release if it finds any of the network functions it looks for there, or a way to start another program (which could send data for Opalro).
- So Opalro has no telemetry, no update check and no license check over the network, and it sends no crash reports.
- Opalro reads and writes only on the computer it runs on.

Your operating system, or a sync tool such as OneDrive, may still move a project's files over a network: when the project is on a network drive or in a synced folder, for example. The operating system or the tool does that, not Opalro.

A later version of Opalro that sends anything will come with a new agreement that says what it sends.
